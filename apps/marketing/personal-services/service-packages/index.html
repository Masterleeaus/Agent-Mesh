Three possible scopes of work.

These categories outline topics for assessment. They are not preset plans, published prices or an availability statement.

01 · DISCOVER

Service assessment

Understand the business, current tools and operating needs before proposing an implementation.

  • Current workflow and systems map
  • Constraints and priorities to review
  • Questions about feasibility and responsibilities
  • Written next-step scope if appropriate

02 · IMPLEMENT

Scoped implementation

Define and work through agreed changes after the proposed scope and dependencies are confirmed.

  • Specified integrations or workflow changes
  • Agreed roles, access and review points
  • Defined deliverables and acceptance steps
  • Separate terms and timing confirmed in writing
See the implementation approach
03 · MANAGE

Ongoing managed service

Describe any continuing responsibility for systems, configured capability or agreed workflows.

  • Defined systems and service boundaries
  • Named responsibilities and review approach
  • Changes handled within agreed scope
  • Commercial and operational terms agreed separately
