## Non-negotiable convergence rules
- Preserve existing working Titan Code systems; extend rather than replace.
- `company_id` is the only tenant boundary.
- `CodeeProviderGateway` remains inference execution authority unless a later pass explicitly proves a safer convergence.
- Browser contracts remain canonical; donor browser code implements them rather than creating a parallel capability namespace.
- Donor code is never activated directly from `imports/`.
- Each pass emits a complete cumulative ZIP and verification receipt.

## Titan Code / Titan Zero separation (locked 2026-09-21)
Titan Code is a private development, testing and Titan Zero management environment. Production Titan Zero has no runtime dependency on Titan Code. Mature reusable browser/runtime technology may be extracted only after proving it here, through a separate production-runtime extraction phase into a hardened Titan Zero browser extension/node. Development-only systems (Agent Mesh, Plan Runner, repository/Git/coding intelligence, Titan Zero development intelligence, builder artifacts and developer diagnostics) remain Titan Code-only.
