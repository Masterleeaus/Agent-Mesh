# Titan Code — Deployment Workforce Laravel Gateway

- Surface: professional deployment/operator console.
- Backend authority: Laravel Deployment Workforce.
- Company boundary: `company_id` only.
- Actor identity: `authenticated` is replaced by Laravel with the authenticated canonical Workforce actor.
- Lifecycle: intake → investigation → engineering → installation → commissioning → handover → change request.
- Reads return source-of-truth projections; writes create governed proposals/receipts and never grant authority.
- Titan Code never writes Client Workforce or Titan Zero state directly.
