# Drafted — landing page

The marketing site for [trydrafted.io](https://trydrafted.io).

Single static HTML page with inline CSS + JS. No build step.

## Deploy

Auto-deploys to Vercel on push to main.

## Local preview

Open index.html in a browser. Or run a quick static server:

    python3 -m http.server 8000

## Stack

- HTML/CSS/JS only
- Geist + Instrument Serif fonts from Google
- Email forwarding via Namecheap → hello@trydrafted.io
- Hosted on Vercel free tier
