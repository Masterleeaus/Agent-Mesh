# Bundled Geist fonts

These variable WOFF2 files are copied unmodified from the official Vercel Geist font package, `geist@1.4.2`, published 2025-05-06. Source: https://registry.npmjs.org/geist/-/geist-1.4.2.tgz; upstream repository https://github.com/vercel/geist-font (package directory `packages/next`).

The downloaded package matched the npm registry SHA-512 integrity and its registry signature verified against npm's published signing key. `OFL.txt` contains the package's SIL Open Font License 1.1.
