# Navigation

Navigation components for application routing and page hierarchy discovery.

## Components

- **ApplicationSwitcher** — dropdown menu for switching between applications/modules
- **Breadcrumbs** — breadcrumb trail with separator and truncation support
- **Sidebar** — re-export of `components/Sidebar` for navigation context
- **TopNavigation** — horizontal top nav bar with active state and badges
- **RoleAwareNav** — navigation wrapper that filters items by user roles/permissions

## Usage

All components accept `style` and `className` props for layout customization.
