# Pagination

Page navigation with number buttons or simple prev/next controls.

## Features
- **Numbers variant** — full page number buttons with ellipsis truncation for large page counts.
- **Simple variant** — just "Previous" / "Next" with a "Page X of Y" label.
- **First/Last/Prev/Next** — `showFirstLast` and `showPrevNext` toggle these controls.
- **Ellipsis truncation** — smart page range calculation using `siblingCount` (default 1).
- **Size options** — `sm` (28px), `md` (36px), `lg` (44px).
