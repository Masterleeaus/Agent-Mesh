# Topbar

Horizontal top bar with a 3-zone layout (left, center, right).

## Features
- **3-zone layout** — `left`, `center`, `right` props place content in each zone; `children` renders between left and center.
- **Sticky** — `sticky` (default `true`) pins the bar to the top with `position: sticky`.
- **Height config** — `height` prop (default `56px`) controls bar height.
- **Border toggle** — `border` (default `true`) shows a bottom border.
