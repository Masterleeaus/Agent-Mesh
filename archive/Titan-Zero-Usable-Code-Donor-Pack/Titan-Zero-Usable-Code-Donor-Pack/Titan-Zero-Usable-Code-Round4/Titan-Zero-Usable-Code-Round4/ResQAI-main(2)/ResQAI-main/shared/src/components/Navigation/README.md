# Navigation

Flexible navigation component with vertical and horizontal layouts.

## Features
- **Vertical/horizontal** — `variant` prop switches between `vertical` (column) and `horizontal` (row).
- **Icon + label + badge** — each `NavItem` supports an icon, label text, and a badge pill.
- **Hover/active states** — hover highlights with `var(--bg-page)`, active with `var(--accent-light)` background.
- **Divider items** — set `divider: true` on a `NavItem` to render a separator.
- **Compact mode** — `compact` reduces padding and font size.
