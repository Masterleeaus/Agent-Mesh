# Tabs

Tabbed navigation with three visual variants and configurable sizing.

## Features
- **3 variants** — `underline` (default), `pills`, `buttons`.
- **3 sizes** — `sm`, `md` (default), `lg`.
- **Badge/Count** — optional `badge` or `count` rendered as a pill.
- **Scrollable** — `scrollable` enables horizontal overflow scroll.
- **Full width** — `fullWidth` distributes tabs evenly.
