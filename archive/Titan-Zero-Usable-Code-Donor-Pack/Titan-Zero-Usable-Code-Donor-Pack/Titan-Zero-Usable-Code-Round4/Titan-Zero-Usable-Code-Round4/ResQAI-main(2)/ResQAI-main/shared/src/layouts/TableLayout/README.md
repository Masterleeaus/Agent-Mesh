# TableLayout

Data table page layout with search, filters, actions, and pagination zones.

## Zones

| Slot         | Description                              |
|--------------|------------------------------------------|
| `topbar`     | Top navigation bar                       |
| `header`     | Page title and description               |
| `search`     | Search input                             |
| `filters`    | Filter controls                          |
| `actions`    | Primary action buttons (right-aligned)   |
| `children`   | Table content                            |
| `pagination` | Pagination controls (centered)           |
| `footer`     | Bottom bar (optional)                    |

## Layout

Search, filters, and actions are arranged in a single responsive row. Search aligns left, filters fill center, actions align right.
