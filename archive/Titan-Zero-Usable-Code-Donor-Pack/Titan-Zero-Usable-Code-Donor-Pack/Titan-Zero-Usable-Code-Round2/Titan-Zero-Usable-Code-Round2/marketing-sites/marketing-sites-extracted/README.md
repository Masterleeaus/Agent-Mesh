# Extracted Marketing Sites

This package contains the two marketing/landing sites extracted from the supplied repositories.

## fieldcrew-marketing-site
Complete FieldCrew public marketing site, including homepage, compiled assets, blog/Jekyll content, SEO files, images, redirects, privacy/contact/checklist routes and deployment configuration.

## fieldops-marketing-site
Standalone extraction of the FieldOps public landing site. Includes the landing page, interactive disruption demo, optimizer logic used by the demo, styles, hero image, favicon, and minimal Next.js project files required to integrate/build it independently.

The original FieldOps operational control-room application is intentionally not included in this folder. Links targeting `/control-room` are preserved so they can be wired to the host repository/application after upload.
