# Skill Map

Canonical skill fields in the Agent 4 contract: skill ID, version, description, instructions, tags, applicable roles/domains, capability requirements, tool requirements, provenance, lifecycle, enabled state and optional company configuration.

Discovery is relevance-first and bounded. Global skills plus the current company's skills are eligible; another company's configuration is not.

A skill is procedural knowledge. It is not a tool, capability declaration, permission or authority grant. No authority field or execution primitive exists in the skill contract.

OpenAcme donor strength: recursive SKILL.md discovery and progressive disclosure. Titan augmentation: explicit provenance/version/lifecycle/company isolation plus hard authority separation.
