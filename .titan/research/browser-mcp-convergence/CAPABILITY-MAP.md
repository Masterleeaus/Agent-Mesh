# Capability Map

Canonical registry remains `packages/tools`; Agent 5 did not create a competing catalogue.

Execution metadata required by the new gateway/provider contracts:
- stable Titan capability name
- provider id
- execution class: native / connected / operated
- company scope
- input/output contract owned by canonical registry
- authority result supplied by canonical evaluator
- risk result supplied by canonical risk path
- idempotency key
- credential handle (never raw secret)
- evidence/outcome verification behaviour
- work/agent/execution correlation

Provider-specific MCP names and browser mechanics are implementation details, not policy identities.
