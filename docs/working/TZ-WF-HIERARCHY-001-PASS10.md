# TZ-WF-HIERARCHY-001 — Pass 10

Pass 10 closes the formal hierarchy cycle with reusable end-to-end verification across Reception, Booking, Dispatch, Jobs and Invoicing. Each representative flow constructs the full Manager → Supervisor → Agent → Worker ancestry, governed direct invocation, least-authority worker task, hierarchy delegation with causality/idempotency, adjacent-tier escalation, approval gate, device-first snapshot/recovery and read-only diagnostics projection.

The verifier deliberately never executes business mutations. Identity, hierarchy, delegation, approval, persistence and diagnostics remain non-authoritative; protected work stops at the authority gate and the existing Business Ops route/domain service remains authoritative.
