# Cleaning Business KPIs — Pass 4

This pass adds cleaning-specific metric definitions without changing the underlying aggregation engine or operational source modules.

The set includes completed jobs, rework count/rate, quote conversion, labour utilisation, recurring revenue, QA exceptions, first-time pass rate, average job value, repeat-customer rate, scheduled completion rate, and evidence quality.

Ratio metrics require explicit numerator/denominator observations. Revenue metrics require explicit invoice/quote values. Nothing is inferred from absence, and no missing value is fabricated.
