Module contract

Signed package

Integrity is SHA-256 and publisher authenticity is ECDSA P-256. The extension pins public keys; signing private keys never ship in the build.

Dependencies

requires.modules supports semantic-version ranges. Missing, incompatible or cyclic dependencies block activation and routing.

Authority grants

authority.requests is declarative. Mutating tools and commands require an active governance grant matching company, module and action.

Version history

Prior module and bundle versions are retained in bounded local history so compatible upgrades can be rolled back without downloading code.

Runtime v2 isolation

Compatibility ranges, bounded lifecycle timeouts, failure quarantine and explicit recovery isolate a failing module without replacing the rest of Titan Zero.

Company module state

Global installation is separate from per-company enablement/configuration. Company controls never create a second tenant boundary; company_id remains canonical.

Suspend bundle

A workforce/team pack can be suspended and resumed as one lifecycle unit without deleting its modules or canonical business data.

Device-first SDK

Local modules may declare local_primary, remote_primary or mirror authority binding. Activation still confers no execution authority.

Events

Module events are local, bounded and isolated by company_id. Event-triggered work inherits the same governance checks.

Packaged code

Executable handlers must ship inside the extension and remain statically catalogued for Chrome MV3. Runtime JSON stays declarative.

Company boundary

company_id is the sole canonical company boundary. Legacy tenant identifiers are rejected recursively.
