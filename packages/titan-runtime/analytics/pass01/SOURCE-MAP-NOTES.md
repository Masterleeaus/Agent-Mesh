# KPI Source Map — Pass 1

Merge 42 contains mature operational producers but no single business-analytics authority. The analytics lane should therefore be a derived, evidence-backed projection layer.

Pass 1 does not create a database, mutate business records, grant authority, or invent missing metrics. It inventories existing authorities and establishes source IDs for the KPI registry planned in Pass 2.

Key rule: a KPI value is valid only when its `company_id`, source/provenance reference, time window and missing-data state are explicit.
