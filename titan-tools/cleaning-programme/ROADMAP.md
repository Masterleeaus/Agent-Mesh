# Titan Zero — Cleaning Business Tools Programme

Programme ID: `TZ-CLEANING-TOOLS-30PASS-001`

This roadmap is stored inside the extension so future passes can read the next required work directly from the ZIP.

Canonical rules: `company_id` is the sole company boundary; AI identity does not grant authority; reuse retained rich Titan/Monica-derived implementations before rebuilding; safety-critical cleaning guidance must use authoritative sources.

## Pass 1 — Canonical Tool Registry [DONE]
1. Create one authoritative registry for every existing and future tool, covering purpose, category, inputs, outputs, launch surface, supported roles, permissions, company_id scope, autonomy limits, AI/provider requirements, costs, offline capability and dependencies.
2. Classify all recovered generic tool families by cleaning-business relevance and role fit without removing generic capability.
3. Add a validated registry loader and tests so malformed, cross-company or authority-ambiguous tool definitions fail closed.
4. Persist this 30-pass programme and pass state inside Titan Zero so each future pass can determine the next required work from the ZIP itself.

## Pass 2 — Tool Runtime Standardisation [NEXT]
1. Give every tool common start, progress, stop, cancel, retry, timeout, success, failure, recovery, history and diagnostics behaviour.
2. Preserve specialist rich interfaces while removing inconsistent duplicate runtime wrappers.
3. Add standard tool-run receipts with provider, model, cost route, authority decision and result status.
4. Certify that tool identity never grants execution authority.

## Pass 3 — Tool Context Engine [PENDING]
1. Create a common context envelope for company, customer, property, quote, booking, job, worker, document, webpage, photo, selected text and workflow context.
2. Normalize all legacy tenant fields immediately to company_id before tool use.
3. Add context minimisation so tools receive only the information needed for the task.
4. Add provenance and freshness markers to tool context.

## Pass 4 — Tool Authority, Cost and Memory [PENDING]
1. Classify tools by read-only, recommendation, drafting, data modification, communication, financial and operational effects.
2. Enforce Titan autonomy and device-first/BYO cost rules at execution time.
3. Create structured tool-run memory so results become reusable business evidence.
4. Add budget, entitlement and provider fallback receipts.

## Pass 5 — Cleaning Writing and Language Suite [PENDING]
